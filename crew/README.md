# Crew pictures (optional)

All four crew members are drawn as DiceBear "Avataaars" cartoon avatars. Their looks are set in the `TEAM` list in `crew.js` (skin, hair style, hair or hijab colour, glasses, facial hair, expression).

To use a picture for someone instead:

1. Put a square, head-and-shoulders image here, for example `crew/brian.jpg`.
2. Add `photo: 'crew/brian.jpg'` to that person's entry in `TEAM` in `crew.js`.

Pictures are shown as they are (`PHOTO_PX = 0`). Set `PHOTO_PX` to a number such as 40 to turn real photos into pixel art instead. The site is public, so only add pictures the person is happy to share.
