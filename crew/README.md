# Crew photos

Drop a square picture of each team member here. The team uses cartoon avatars, shown as they are:

| File | Crew member |
| --- | --- |
| `brian.jpg` | Brian (Engineer) |
| `sidra.jpg` | Sidra (Botanist) |
| `quan.jpg` | Quan (Geologist) |

Tips:

- Use a **square, head-and-shoulders** photo with the face in the middle. Non-square photos are cropped to the centre square.
- Any size works; something around 400 x 400 is plenty. Keep files small (under ~200 KB) so the page loads fast.
- A plain background looks best once pixelated.
- To make the pixels bigger or smaller, change `PHOTO_PX` in `game.js` (default 40; lower = chunkier).
- No photo yet? The game uses the drawn portrait instead, so nothing breaks.

To use another file name or a `.png`, change the `photo:` path for that person in the `TEAM` list in `game.js`.

The photos show on the start screen, the crew cards, the debriefs, and with the helmet off during the crew introduction. The site is public, so only add photos the person is happy to share.
